# IA/360 Avanzado

Plataforma personal de formación e investigación avanzada sobre inteligencia artificial de Elian Facundo Yorlano.

Incluye 76 seminarios, 16 módulos, más de 100 fuentes primarias, laboratorios, capstones, notas y seguimiento de progreso.

## Publicación

El sitio se despliega automáticamente mediante GitHub Pages desde la rama `main`.

## Progreso

- Funciona localmente con `localStorage`.
- Puede sincronizarse entre dispositivos mediante Supabase Auth y PostgreSQL con Row Level Security.
- Nunca se debe publicar una clave `service_role` o secret key.
